- Focus on **navigation, localization, sensor fusion, testing, debugging, and reliable robot behavior**.
- Planned stack includes **Nav2, SLAM Toolbox, robot_localization, EKF, TF2, Gazebo, Foxglove, and C++**.

- Build a multi-robot system for **mission scheduling, task allocation, fleet monitoring, traffic coordination, and telemetry**.
